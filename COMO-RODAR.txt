SONORA — como usar
==================

Repositório: https://github.com/PAULO4800/sonora

O que você precisa
------------------
1. Node.js 22 ou mais novo  →  https://nodejs.org
   (na instalação do Windows, marque a opção "Add to PATH")
2. Uma chave da ElevenLabs  →  https://elevenlabs.io
   Cole a chave em Configurações, dentro do app.
   Ela fica salva neste navegador, neste computador.


Passo a passo (Windows, Mac ou Linux)
-------------------------------------
1. Baixe o projeto com Git:
     git clone https://github.com/PAULO4800/sonora.git
     cd sonora

   Sem Git: extraia o ZIP para uma pasta, por exemplo C:\Sonora ou ~/Sonora,
   e abra o terminal NESSA pasta.

2. Instale as dependências (só na primeira vez, demora 1–2 minutos):
     npm install

3. Inicie o app:
     npm run dev

4. No navegador, abra:
     http://localhost:8080

5. Clique em Configurações, cole a chave da ElevenLabs (sk_…) e salve.

Pronto. Cole o texto, escolha a voz (Krok é a padrão em português do Brasil)
e clique em Gerar voz.


Se der erro
-----------
- "npm não é reconhecido"
    Node.js não está no PATH. Reinstale o Node e reabra o terminal.

- "Configure sua chave em Configurações"
    Abra Configurações, cole a chave da ElevenLabs e salve.
    A chave fica só neste navegador.

- "Chave da ElevenLabs inválida"
    Confira se copiou a chave completa em elevenlabs.io → Profile → API keys.

- Porta 8080 ocupada
    Feche o outro programa que está usando 8080.

- Gerar voz falhou / cota
    A cota da sua chave ElevenLabs esgotou ou a internet caiu. Tente de novo.


Atalhos no app
--------------
Ctrl + Enter (Windows) ou ⌘ + Enter (Mac) gera a voz.
As gerações recentes ficam salvas neste navegador, neste computador.


Parar o servidor
----------------
No terminal, pressione Ctrl + C.


GitHub Actions
--------------
O arquivo .github/workflows/ci.yml roda sozinho em todo push/PR:
  npm install → typecheck → testes → build.

Para disparar na mão: GitHub → Actions → CI → Run workflow.
A chave da ElevenLabs não vai no CI. Use Configurações no app.
